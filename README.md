
# ⚡ Neon Syndicate

A cyberpunk trading game where players buy, sell, and travel between dynamic markets.

## ✨ Features
- Dynamic prices and trading
- Multiple districts
- Inventory and credits management
- Random events and localStorage

## 🛠️ Technologies
HTML • CSS • JavaScript
